# Karan Saini | Portfolio Website

A cinematic, interactive portfolio website featuring custom angular ribbon navigation, fluid cursor trail physics, interactive Domain Expansion, and an AI Guide powered by an anime mentor persona with speech synthesis.

## Live Deployments
- **GitHub Pages:** [https://karanxgojo-cmyk.github.io/portfolio/](https://karanxgojo-cmyk.github.io/portfolio/)
- **Vercel:** Connected via GitHub deployment

## Features
- **Cinematic Navigation:** Custom angular ribbon shards with staggered entrance animations.
- **Dynamic Scene Colors:** Theme accents adapt automatically across Home, Domain, Projects, About Me, and Contact pages.
- **Interactive Domain Expansion:** Immersive domain experience with video loop constraints.
- **Satoru Gojo AI Guide:** In-browser intelligent assistant answering questions about academic milestones at IIIT Ranchi, engineering skills, and verified projects, with built-in voice playback via the Web Speech Synthesis API.
- **Real SVG Branding:** Authentic multi-color vector icons for Gmail, LinkedIn, GitHub, Phone, and Google Maps.
- **Zero Framework Overhead:** Pure HTML5, CSS3, and modern JavaScript (ES6+).
